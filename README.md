# Atividade 5 - Node.js e Express

Aplicação simples de coleta de feedbacks de alunos, desenvolvida com Node.js e Express.js.

## Aluno
Gabriel Kaue

## Professor
Ranyelson Neres

## Funcionalidades

- Envio de feedbacks com nome e comentário
- Listagem de todos os feedbacks enviados
- Remoção de feedbacks

## Como rodar

1. Instale as dependências:
```bash
   npm install
```

2. Inicie o servidor:
```bash
   node server.js
```

3. Acesse no navegador: `http://localhost:3000`

## Tecnologias

- Node.js
- Express.js
